# `@mgravey/loom-workspace-fsa`

Binary project-workspace adapters for the browser File System Access API and Origin Private File
System (OPFS), plus a Loom.js plugin adapter.

```sh
pnpm add @mgravey/loom-workspace-fsa
```

Direct-directory access requires a supporting browser and user permission. Applications should make
read-only versus read/write authority visible before opening a directory.
