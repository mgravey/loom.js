Loom Secure Model Bridge privacy disclosure

This bundled disclosure describes the extension build. Before Chrome Web Store publication, the publisher must provide the completed public policy URL and verified contact details.

Single purpose

Authenticate a user-initiated Loom session and relay its model requests without exposing provider credentials to the website.

Information handled

  • A refresh credential and account-routing ID stored only in extension session storage, cleared when Chrome exits.
  • Short-lived credentials used only for provider requests and not persisted by Loom.
  • User prompts, selected project context, model settings, and tool results sent to the configured ChatGPT model endpoint.
  • Sanitized status, streaming output, and error codes returned to the authorized Loom origin.

Not collected

The extension does not request or inspect browsing history, unrelated page content, cookies, geolocation, advertising identifiers, or analytics telemetry.

Retention and deletion

Use Remove stored authorization, disable the bridge, clear extension data, or uninstall to remove extension-owned authentication state. This removes local state; it does not itself revoke a grant held by the provider.

Public policy and support

Read the complete public privacy policy or contact support.

Limited use

Information is used only for the disclosed single purpose and in accordance with the Chrome Web Store User Data Policy, including Limited Use requirements. It is not sold or used for advertising or credit decisions.
