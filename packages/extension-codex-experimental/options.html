ChatGPT account

When you explicitly sign in and run Loom, this extension normally stores a refresh credential and account-routing ID only until Chrome exits. You may separately choose to remember them in this Chrome profile. It sends authentication exchanges to auth.openai.com. For a model run it returns a short-lived access token and the stored routing ID to the authorized Loom workbench, which sends prompts and selected project context directly to chatgpt.com. If the browser fails before an HTTP response, the extension retries that request and temporarily processes its model content.

Refresh and ID credentials are not exposed to the Loom website or browser runtimes. The authorized workbench temporarily receives a short-lived access token. The extension does not inspect unrelated pages, browsing history, or cookies, and it contains no developer analytics. Read the extension privacy disclosure.

Private computers only. Persistent extension storage is not an encrypted credential vault, and anyone using this unlocked Chrome profile may be able to use the connected account.
