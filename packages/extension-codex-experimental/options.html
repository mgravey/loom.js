Loom Secure Model Bridge

This integration is unsupported and may stop working without notice. It is not enabled by default. Refresh credentials remain inside this extension and are never exposed to Loom pages.

Before you enable the bridge

When you explicitly sign in and run Loom, this extension stores a refresh credential and account-routing ID only in extension session storage, which is cleared when Chrome exits. It sends authentication exchanges to auth.openai.com and sends your Loom prompts, selected project context, tool results, and model settings to chatgpt.com to produce the response you request.

Credentials are not exposed to the Loom website or browser runtimes. The extension does not inspect unrelated pages, browsing history, or cookies, and it contains no developer analytics. Read the extension privacy disclosure.
